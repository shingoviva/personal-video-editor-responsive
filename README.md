## 2.2.43 — 素材終端で音声が再開する不具合

実際の素材終端と編集上の長さがずれると、終了した音源へplayを呼んで先頭から再開する不具合を修正しました。iPhoneでは素材終端を時計の待機状態にせず、編集上の終了まで進めて停止します。映像・下位レイヤーも終端を記録し、意図しないシーク・再開を抑止。明示的な再生・シーク、新しいクリップ、設定した音声ループは使用できます。再生フレーム内の例外時も音声を停止します。

## 2.2.42 — 再生停止後の残留音対策

音声回路を無音・フィードバック0の状態で接続し、停止時は共通出力と各音源を消音、ディレイの予約処理を取り消してAudioContextを休止します。次の再生は休止完了を待って復帰。停止後の遅いplay完了や停止中の音量更新から音が復活することを防ぎます。BGMも停止時に消音します。

編集点の旗はクリック／タップで選択、横ドラッグで時刻を変更、Delete／Backspaceで削除します。iPhoneでは選択後の下部「削除」も使用できます。ダブルクリック／ダブルタップまたはMacの右クリックで名前・秒数・削除の詳細を開きます。Escapeで選択解除。編集点を選ぶとクリップ選択を解除し、削除対象を分離します。ドラッグ・削除はUndo／Redo／保存に対応。Shiftドラッグは吸着・フレーム丸めなし。

## Macで起動する

1. ZIPを展開し、フォルダ全体を任意の場所に置いてください。
2. Python 3.9以降と、libx264・overlay・zscale・tonemap・vidstabを含むFFmpegが必要です。文字はブラウザで透明PNGへ描画してから合成するため、通常はFFmpegのdrawtextを必要とせず、日本語も画面と同じフォントで書き出せます。Homebrewを導入済みの場合、以下をターミナルへ貼り付けます。

```bash
brew install python ffmpeg-full
```

3. `Launch.command`を開きます。同じ編集画面がブラウザに開きます。FFmpegは同梱していません。
4. 開かない場合はターミナルへ `bash ` と入力し、続けて `Launch.command` をドラッグしてEnterを押してください。macOSが確認を表示する場合は、内容と配布元をご確認のうえ開いてください。
5. 終了は起動したターミナルで **Control+C** です。起動中はターミナルを閉じないでください。

Homebrew未導入の場合は [brew.sh](https://brew.sh/) の公式手順で導入してください。インストール済みの通常版FFmpegも利用できますが、手ぶれ補正・HDR変換・テキストはビルド構成に依存します。起動スクリプトは `ffmpeg-full` のインストール先を優先します。

## 保存と再開

編集はブラウザへ自動保存し、Mac版ではディスクにも保存します。「保存」または⌘Sで `.project` ファイルをダウンロードできます。ファイルには編集内容と素材の参照が含まれ、動画本体は含みません。

右上の「全てをリセット」は、確認画面を経て現在の読み込み素材、タイムライン、調整、編集履歴を消去します。確認画面の「現在の編集を保存」から、リセット前の `.project` ファイルを保存できます。端末版では、この編集用に保持した素材コピーも削除します。元素材と書き出し済み動画は変更しません。

別のブラウザやMacへ移す場合は、.projectを開き、元と同じファイル名・サイズの素材を読み込んで再リンクしてください。Mac版の「開く」では保存済みプロジェクトも選べます。編集履歴は最大60回で、ブラウザを閉じるとリセットされます。

### Mac内の保存先

`~/Library/Application Support/Personal Video Editor/`

- `media/`：読み込んだ動画・BGMのコピーとメタデータ。元の場所の原本は変更しません。
- `cache/`：プロキシ、サムネイル、波形、解析結果、処理プレビュー。
- `projects/`：自動保存したプロジェクト。
- `exports/`：完成MP4 / MOV。
- `logs/`：処理段階・所要時間・検証結果・FFmpegエラーの診断記録。失敗画面からダウンロードできます。

RAMを抑える代わりにディスクを使用します。元ファイルのコピー、プロキシ、スタビライズ中間映像、音声の一時ファイルを保存できる空き容量が必要です。成功・失敗・キャンセル後、書き出し中間フォルダは削除します。生成中は一時ファイルを使い、検証に通った出力だけを確定します。生成ファイルが不完全な場合は1回だけ再生成します。入力形式や設定のエラーは自動再試行しません。最終MP4は全尺をデコードして検証するため、その分だけ完了まで時間がかかります。

不要なキャッシュはアプリ終了後にFinderから削除できます。次回IMPORTの「プロキシを生成 / 再試行」で再作成してください。`media/` と `projects/` は必要なプロジェクトが参照していないことを確認してから整理してください。原本・完成MP4・.projectのバックアップを推奨します。

## 既知の制約・未検証

- 実機のiPhone HEVC/HDR/Dolby Vision、長尺VFR、Safariでの再生、Apple Siliconでの性能、Instagram実投稿は未検証です。合成素材によるネイティブ処理試験を同梱しています。

- ランプは32分割近似です。音声は区間ごとにピッチを維持して処理しますが、急変部や極短区間では音のつなぎ目が聞こえる場合があります。BGM主体の演出では原音ミュートを選べます。

- GPUとFFmpegは共通のRGB補正式を使います。LUT補間・圧縮・表示色管理による差は残ります。手ぶれ補正・ブレンド・1.0を超える音量も処理プレビューで確認してください。
- 手ぶれ補正の事前クロップ推定・光学フロー・AI補間・顔/視線/ポーズの意味認識・写真ルック転写・ビート検出・ジャイロ・自動追尾クロップは未実装です。
- J/Lは前後1秒の移動です。逆再生シャトルは未実装です。
- CPUのlibx264を採用しています。VideoToolboxは能力を検出しますが、実機検証が済むまで自動選択しません。

## 1.3 — 2レイヤーと直接編集

- V2（上段）とV1（下段）へクリップを配置できます。重なる区間はV2を表示します。同じ段では配列上で後のクリップ（通常は後から追加したクリップ）が優先されます。
- クリップ中央をドラッグして時刻・レイヤーを移動。両端の持ち手をドラッグしてトリミング。CUTには開始・終了スライダー、配置時刻、レイヤーの数値／選択操作もあります。
- 空いたレイヤーをタップすると貼り付け先が選ばれます。コピー、切り取り、貼り付け、複製は上部ボタンと⌘C／X／V／D（WindowsはCtrl）に対応。貼り付けは再生ヘッドへ、複製は元クリップの末尾へ配置します。
- 削除は他のクリップの位置を変えません。上段を削除すれば下段が現れます。前詰め削除は同じレイヤーで削除区間の後にあるクリップだけを詰めます。
- 吸着ボタンで境界スナップを切り替えます。ドラッグは30fps単位が基本です。Optionドラッグは複製になります。
- 1回のドラッグはUndo 1回で戻ります。⌘Z、⌘ShiftZ、CtrlY、および画面のUndo／Redoボタンに対応します。
- 原音は表示中のクリップだけを採用し、BGMは全体に流れます。上段の透明部分は下段と合成されます。
- 速度ランプを分割すると元の速度積分を保持します。速度やカーブを再指定した場合は、そのクリップ範囲で新しいランプを設定します。
- 再生用タイムラインを事前計算し、速度積分とGPU設定をキャッシュ。画面描画を最大30回／秒に抑え、ドラッグ中のサムネイル再生成を避けています。Macプロキシは引き続き利用できます。
- 旧プロジェクトは従来の並びを維持して読み込みます。2レイヤーのプロジェクトはこの版のMacエンジンで書き出してください。旧Mac版へ戻すと配置が正しく再現されません。

実機でのタッチ操作・Safariの性能・長時間4Kの性能は未確認です。Mac版のレイヤー書き出しは区間ごとに処理するため、細かく重ねるほど処理時間が増えます。元素材は変更しません。

## 1.4 — 静止画・音声の追加と素材管理

「素材を追加」から動画・静止画・音声を混在して複数選択できます。ドラッグ＆ドロップも同じ動作です。読み込めないファイルが含まれても、読み込み済みの素材は維持し、残りを続けます。

- 素材一覧：すべて／動画／静止画／音声で絞り込み、名前検索、追加順／名前順、使用箇所の数を表示。
- 静止画：JPEG・PNG・WebP。初期表示5秒、CUTや両端ドラッグで表示時間を変更。V1／V2両方に配置でき、クロップ・カラー・MP4書き出しにも対応します。透明部分は黒背景へ合成します。HEIC・RAW・GIF・SVG・TIFFはJPEG等へ変換してください。静止画には速度／手ぶれ補正／動き解析の操作を出しません。
- 大きな静止画：100MB／8,000万画素を上限にします。プレビューは長辺1280px、サムネイルは320pxに縮小。画像を切り替えると前のプレビュービットマップを解放します。ブラウザの初回読み込み時には1枚をデコードします。

- 表示名は自由に変更できます。元ファイル名は保持するため、再リンクへの影響はありません。
- 「一覧から外す」「未使用を整理」はプロジェクト内の未使用素材だけが対象です。元ファイルや端末内保存データは物理削除せず、Undoで戻せます。
- 同じ名前・サイズで接続済みの素材は重複追加しません。静止画・音声も既存の端末内保存、.project保存／再リンクの対象です。

Mac版で静止画を含む書き出しをする場合は、この版をダウンロードし直してください。iPhone実機での新しい読み込みUI・静止画書き出し・保存の確認はまだ行っていません。写真はSDR／sRGB推奨で、HDR静止画やICCプロファイルの厳密な一致は保証していません。

## 1.6.0 — 3 video / 4 audio

映像はV1・V2・V3の3段。上の段、同じ段では後に置いたクリップが優先されます。V3/V2の透明フェードから下の映像を合成します。新しく作る静止クリップはV3へ配置します。

SOUNDの「原音を音声トラックへ分離」で、動画の範囲・速度ランプ・音量・フェードを引き継いだ音声クリップを作成し、動画側をミュートします。その後は映像と音声が独立し、どちらの移動・カットも他方を変更しません。映像を消しても分離音声の素材は保持します。

音声はA1原音・A2環境音・A3 BGM・A4効果音の4段。名前・用途は自由。同じ段の重なりは後のクリップを優先し、別の段は同時再生します。中央ドラッグで位置と段、両端でトリム。コピー／貼り付け／複製／分割／削除／前詰め／Undo・Redoに対応。音量・IN/OUTフェード・速度とランプ・ループをSOUNDで調整できます。段ごとのMはミュート、Sはソロ。ソロ時は未分離の動画原音も止めます。

音声ファイルは素材一覧から配置、またはSOUNDの「音声ファイルを追加」。複数選択時は選んだ段へ順に配置します。旧プロジェクトのBGMはA3へ同じ長さ・ループ・音量で移行します。音声が映像より長い場合は、その部分を黒映像としてMP4に残します。音声だけのプロジェクトの書き出しは未対応です。

Macは最大3段を一時ファイルで合成し、音声は最大4入力へまとめて混ぜます。端末版は最大3映像系統と4音声系統を使い、音声は0.25秒単位で混合します。1倍を超える原音量・極端な速度・スタビライズは処理プレビューで確認してください。端末の音声速度変更は音程も変化し、Macのatempo処理とは異なります。

## 1.7.0 — RESPONSE / QUALITY

- コピーしたクリップから「属性ペースト」を実行し、色・ルック、スケール・位置、速度・補間・手ぶれ補正、映像フェード、音声設定を選んで移せます。素材、配置レイヤー、開始位置、IN / OUTは保持します。`⌘ Shift V`でも開け、1回のUndoで戻せます。
- 再生中の映像・音声同期を30Hzへまとめ、FX表示の不要なDOM再生成を停止しました。下段映像の読み込み中に操作が続いた場合は、最後の要求だけを保持して処理します。
- iPhone端末書き出しの手ぶれ補正は、すでに累積されたカメラ軌跡を正しく平滑化するよう修正しました。画面周辺の複数領域から動きを推定し、人物の動きに引かれにくくしています。局所的な直線軌跡を使い、意図的なパンを残しながら細かな揺れを減らします。
- Mac版vidstabはグローバル最適化、bicubic補間、固定optzoomを明示。補正用の中間映像をCRF 10へ上げ、不要な中間音声エンコードを削除しました。
- iPhone端末書き出しは高速再生時の音声へ短い帯域制限補間を使い、折り返しノイズを抑えます。4レイヤーの合成後は左右連動のリミッターでピークを保持し、単純な波形切断を避けます。
- Mac版の速度ランプ音声は32-bit float PCMで中間処理し、最終ミックスは自動増幅を無効にしたリミッターを使用。再エンコード時のAACを48kHz・256kbpsへ固定しました。

手ぶれ補正はGoogle ResearchのL1最適カメラ軌跡の考え方と、FFmpeg／vid.stabの実装・設定を参照しています。ブラウザ版は軽量な平行移動補正、Mac版はvid.stabの回転を含む補正です。

Clip Gain Envelopeの波形は素材を順番にストリーム解析し、4096個のピーク値だけを保持します。0〜-24 dBの操作領域を広く取り、音量差を見やすくしました。速度ランプを変更してもBreakpointは同じ元音声位置へ追従します。Previewは音声クロック上へGain曲線を予約し、Stepの5msランプを画面更新頻度から独立させます。
