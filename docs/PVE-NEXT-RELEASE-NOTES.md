# Phase2b時点のリリースノート案（履歴）

2.2.85公開前候補の完成版は [PVE-2.2.85-RELEASE-NOTES.md](PVE-2.2.85-RELEASE-NOTES.md) を参照してください。以下は版更新前の記録です。

- フラッシュFXを含むFX合計400個までのパターン編集に対応します。フラッシュ以外のFXは100個までです。超過は黙って削除せずエラーにします。
- Ctrl/Altを押して選択済みclip本体をドラッグすると、複数clipを相対時刻・トラック・設定を保って複製できます。元素材ファイルは共有し、複製群は独立したIDを持ちます。Esc取消・1回のUndo/Redoに対応します。
- 配置が変わらないoverlayのDOM/操作結合を再利用し、多数FX時の再描画を軽くします。Undo/読込時は表示・操作対象を更新します。端末すべてでの速度改善を保証するものではありません。

## project互換性 — 更新前に別名backup

FXが100個を超えるprojectは保護用の**project形式2**で保存します。アプリの版番号とは別です。旧2.2.84はこのファイルを読み込み拒否します。形式1のまま旧版へ渡すと101個目以降を黙って切り捨てるため、この保護を付けています。

既存の形式1は読み込めます。形式2はFXを100個以下へ減らしても保護を残します。旧版へ戻す場合は更新前の別名backupを使用し、新しいprojectを上書きしないでください。素材を削除・物理複製する移行は行いません。

## 制限

- 動画/画像clip200、音声clip200、素材200、TEXT300、V3/A4/F-T3の既存上限は維持します。
- 選択動画に連動する音声は既存仕様どおり一緒に複製します。音声単独の複製は独立音声になります。縦ドラッグで群のトラックを付け替える機能は追加しません。
- WebKit native AACの音質差、Mac非等速WSOLAの同期、素材コピー旧世代の残存など既存制限は未修正です。
- 実iPhone・長尺4Kの受入は別途必要です。Mac WebKitの検証を実機確認とは扱いません。
- Quick/Master Export、Speed新機能、text最適化02、Feature Labは含みません。

本書は案です。正式な版番号更新と公開は検証結果のユーザー確認後に行います。

> 互換保護は旧版の新規読み込みを拒否するものです。すでに開いている旧版タブ/旧Macアプリの自動保存を止めることはできません。更新前に旧タブで保存・退避して閉じ、同じprojectを旧版と新版で同時に編集しないでください。
