# PVE 2.2.85 — FXパターン編集

- 多数のカメラフラッシュを配置できます。FX合計400個、非フラッシュFX100個までの予算です。超過する追加・複製は明示的に拒否します。
- 複数選択したクリップをCtrl/Alt＋ドラッグでまとめて複製できます。相対時間・空白・トラック・設定を保持し、音楽に合わせたFXパターンを繰り返し配置できます。1回のUndo/Redo、Esc取消に対応します。
- 内容が変わらないoverlayのDOM・操作結合を再利用し、大量FX時の再描画を改善しました。操作全体の速度は端末・FXの種類に依存します。
- FX100個超を含むprojectを保護用の形式2で保存し、旧版による黙った切り捨てを防ぎます。形式1も引き続き読み込めます。

## 更新前の注意

形式2のprojectは旧2.2.84では開けません。更新前のprojectを別名でバックアップしてください。古いブラウザタブやMacアプリを閉じ、同じprojectを旧版と新版で同時編集しないでください。すでに開いた旧版の自動保存を新形式の保護だけで止めることはできません。

## 継続する制限

Mac非等速原音の同期誤差、WebKit native AACの品質差は継続します。重要な音声は比較試聴してください。素材解析待ち、Mac書き出し時間、初回起動のばらつきは今後の改善対象です。実iPhoneの最終操作確認はユーザーが行います。大量FXや全端末での快適性を保証するものではありません。
