- `dist/index.html`、`app.js`の`renderInspector` / `audioInspector` / `fxInspector` / `exportDialog` / コンテキスト操作、`iphone-ui.js`、時間・音量・保存モジュールを確認しました。

## 2.2.83指摘4件の現行再現

以下はPhase 1a修正前の調査結果です。B1はその後[安全性修正を実装・検証](PVE-B1-STORAGE-SAFETY.md)しました（未公開）。B2もその後[形状保持修正を実装・検証](PVE-B2-ENVELOPE-SAFETY.md)しました（未公開）。B3は[点数制限修正](PVE-B3-ENVELOPE-LIMIT.md)、B4は[時間基準修正](PVE-B4-TIMELINE-TIMING.md)を実装・検証しました（未公開）。以下の再現表は修正前の記録として残します。

関数を直接importし、データのみの最小ケースで検証しました。ストレージは既存ファイルを模したMapと失敗するwriterです。実ファイルの破壊・実機の容量不足試験は行っていません。

| ID | 結果（事実） | 根拠・影響の区別 |
|---|---|---|
| B1/P0 | `copyMediaToProject`で既存`m-shot.mov`へのwriteを失敗させると、catchの`removeEntry(name)`で既存コピーが消えた | `project-storage.js:85–90`。新規作成か既存かを区別しない。実ユーザーデータの消失発生率・実被害は未調査 |
| B2/P0 | 0秒-12dB hold→1秒0dB→2秒-6dBを0.998秒で分割すると、元の切断点-4.8dBに対し右先頭-12dB。0.997秒も元-7.2dBに対し左/トリム後-12dB | `splitEnvelope`/`trimEnvelope`は境界採取で`stepRamp=0`、再生は既定5ms。境界前後の短いランプ形状が変わる。聴感上の程度は未確認 |
