# PVE 2.2.84 — 安定化アップデート

保存、音量編集、フレーム精度、音声同期、ブラウザMP4互換性を改善しました。大規模なUI変更や新しいSpeed機能は含みません。

- **素材保存**：再コピーや書込み失敗で既存の有効な素材を失わないよう、新しい世代へ書き込んでから参照を確定します。失敗後の再試行にも対応します。
- **音量編集**：holdの短いランプ内で分割・トリムしても形状を保持。256点を超える編集で末端や追加点を黙って捨てません。通常編集上限は1024点で、超過する操作は状態を変えず理由を表示します。編集境界の保持に必要な点は別途保持します。
- **フレーム精度**：編集fpsを素材・書き出しfpsから独立させ、23.976〜60fpsの時間管理とフレーム送りを整合させました。吸着OFFでは30fpsへ勝手に丸めません。音声のサブフレーム時刻を保持します。
- **Mac書き出し**：等速音声で不要な速度処理を避け、音声先行を改善。動画時計のための追加再encodeを廃止し、copy concatで映像とtransitionを維持します。
- **ブラウザ書き出し**：AAC encoder delayを各書き出しで実測し、素材AACのprerollとMP4 priming表現を改善。Chrome／WebKitでの音声時刻の互換性を高めました。固定44ms補正ではありません。

## 既知の制約

- **Mac非等速の原音**：既存WSOLAによるタイミング誤差が残ります。音楽を等速の別レーンへ置き、速度変更クリップの原音をmuteする方法はありますが、台詞や環境音も失うため万能な回避策ではありません。PCM出力だけでは解決しません。
- **iPhone／Safari系のAAC**：素材・波形・圧縮条件によってnative codecの音質差があります。重要音声は元音と比較試聴し、必要ならMacで仕上げてください。音声bitrateの変更で必ず改善するとは保証していません。
- **長尺ブラウザ出力**：過去に単発のworker異常があり、直近の限定反復では再現していません。失敗時は編集を保持して再試行し、完成ファイルを独立再生で確認してください。
- **素材コピー世代**：安全のため、明示的な再コピーでは旧世代を残します。通常のproject上書き保存だけでは増えません。自動整理は今回追加していません。参照を確認せず素材ファイルを削除しないでください。

更新後は一度再読込してください。編集中の旧版タブはprojectを退避してから再読込します。開いたままの旧版タブを自動移行する処理はありません。

## 以前のprojectとバックアップ

更新前にprojectと素材フォルダを別名でバックアップしてください。素材は自動削除せず、既存の秒単位の時刻も勝手に変更しません。編集fpsがない旧projectには30fpsを補います。

保存schema番号は1のままですが、hold境界情報、多数の音量点、編集fpsを追加しています。**2.2.84で保存したprojectを旧版へ戻すと、音量形状や点数・編集fpsを保持できない場合があります。** 旧版でそのファイルを上書きせず、退避した更新前projectのコピーで再開してください。アプリだけ旧版へ戻しても、新形式データの完全互換は保証しません。

開発者向けの方式・検証・公開状態は[リリース報告](PVE-2.2.84-RELEASE-REPORT.md)を参照してください。
